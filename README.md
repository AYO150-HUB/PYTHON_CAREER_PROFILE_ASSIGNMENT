
# CSC334 – Python II
## Database Management Exercises

This repository contains three database management
exercises implemented using Python and SQLite.

### Exercise 1: Student Record Management
- Create university.db
- Create students table
- Insert five student records
- Retrieve all student records
- Retrieve students by department
- Update student level
- Delete student records

### Exercise 2: Course Registration Database
- Create students table
- Create courses table
- Create enrollments table
- Register students
- Register courses
- Enroll students in courses
- Retrieve student and course information
- Demonstrate table relationships using JOIN

### Exercise 3: Library Management System
- Book registration
- Book retrieval
- Book searching
- Book modification
- Book deletion
- Parameterised SQL queries
- Exception handling

### Technologies Used
- Python
- SQLite
- SQL
- Visual Studio Code
- Git and GitHub

### How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project in VS Code.
4. Navigate to the exercise folder.
5. Run the corresponding Python file.

Example:

python studentRecords.py
